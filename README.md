# Longbao

Design files for the Longbao full pin breakout for the Baochip-1x.

The design is split into two halves, a small HDI board that uses laser-drilled vias to break out all the pins,
and a large conventional board that simply fans the break-out to castellated holes for easy prototyping.

The intention is that users who do not want to fab out an HDI board could re-use the HDI board in their design
as a "SOM".
